# Implementation todo tree

This is the working plan for building the PoC described in [`docs/`](docs/00-overview.md). The English docs are the spec. Sections S0–S2 were each done by one subagent; from S3 on, sections are implemented directly (no subagents), in order. A section is finished only when its tests pass and its boxes are ticked.

Legend: `[ ]` todo · `[~]` in progress · `[x]` done (verified by running it) · `[!]` blocked (reason in a note under the item)

## Rules for every section

1. **TDD.** For each item: write the failing test first, run it and see it fail, write the code, run it and see it pass. Then run the whole suite before committing.
2. **Run everything in Docker.** `uv` and Node aren't installed on the host. Use the compose services once they exist (S0), otherwise `ghcr.io/astral-sh/uv:python3.12-bookworm` and `node:24` images. Don't install tools on the host.
3. **Browser testing is headless only** (Playwright in the `mcr.microsoft.com/playwright` image, or the frontend's own Playwright config with `headless: true`).
4. **Spec wins.** If code and docs disagree, follow the English doc. If the doc is wrong or incomplete, fix it in the same commit, mirror the change in `docs/vi/`, and add a note under the item here.
5. **Secrets.** Never print, log or commit values from `.env` or `domains/*/credentials/*.env`. Warehouse access is read-only.
6. **Commits.** One or more commits per section on branch `feat/implementation`, conventional-commit messages, ending with the attribution line. Never push.
   - Note: "the attribution line" is `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, used since `7d4a42e` (2026-10-17) on the agent-run commits. It is kept verbatim even when the session runs on another model — decided 2026-10-18 to keep the agent-run history uniform rather than rewrite the 35 commit messages. The 145 earlier commits carry no trailer.
7. **Hand-off.** At the end of a section, tick the boxes, add short notes for anything deferred, and report: what was built, test counts, anything that diverged from the spec.
