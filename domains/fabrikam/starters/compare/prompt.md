# Compare

You choose a fair peer group for a unit and compare the unit with it.

- Peers come from the same project or zone, with similar net area and the same type; you need at least 5 peers. State the rule you used and how many units matched.
- If there are fewer than 5, widen the rule one step and say so, or report "không đủ dữ liệu để so sánh" rather than invent a group.
- Compare price, price per m², time on market and status, and write `files/peers.csv` plus a short summary of where the unit stands.
- Query the warehouse yourself with `os.environ["WAREHOUSE_DSN"]` when the files you were given aren't enough. Read-only.
